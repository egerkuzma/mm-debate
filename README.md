# mm-debate

Два агента Claude Code с противоположными характерами спорят друг с другом
в треде Mattermost. Вы задаёте тему, они говорят по очереди, вы читаете.

Каждый агент — отдельный бот-аккаунт со своим файлом характера и своей сессией
Claude Code. Очерёдность держит диспетчер: сами боты друг на друга не реагируют,
иначе разговор ушёл бы в бесконечный цикл.

## Как это устроено

- один тред Mattermost = один спор, у каждого агента своя сессия внутри него
- диспетчер подставляет в промпт последнюю реплику оппонента
- `стоп` в треде заканчивает спор, `дальше` продолжает после автопаузы
- любая другая ваша реплика подмешивается в промпт следующему говорящему

## Что нужно

- Node.js 18+
- установленный и авторизованный [Claude Code](https://docs.claude.com/en/docs/claude-code)
-self-hosted Mattermost с включённым созданием ботов
  (System Console → Integrations → Bot Accounts)

## Установка

1. Заведите два бот-аккаунта: Integrations → Bot Accounts → Add Bot Account.
   Роль Member, галочки `post:all` и `post:channels`. Добавьте обоих в команду
   и в канал.

2. Ставим:

```bash
git clone https://github.com/ВАШ_АККАУНТ/mm-debate
cd mm-debate
npm install
cp .env.example .env
```

3. Кладём токены в `.env`. **Порядок важен**: каталоги персонажей сортируются
   по алфавиту, поэтому `MM_TOKEN_A` достаётся первому (`novator`),
   а `MM_TOKEN_B` — второму (`skeptic`).

4. Впишите свой id пользователя Mattermost в `ALLOWED_USERS`, иначе запустить
   спор сможет любой участник канала.

5. Запускаем:

```bash
node debate.js
```

## Как начать спор

Упомяните обоих ботов в канале:
@novator @skeptic куда движется AI? Новатор, твоё первое слово


Если не указать, кто начинает, первым пойдёт тот, кого упомянули раньше.

## Персонажи

Каждый каталог внутри `personas/` — это один агент, а лежащий там `CLAUDE.md`
задаёт характер. Claude Code читает его при каждом вызове, так что правки
подхватываются со следующей реплики, перезапуск не нужен.

В комплекте двое: Скептик и Новатор. Замените на кого угодно — именно имя
каталога сопоставляется с ботом, так что для `personas/optimist/` понадобится
свой слот под токен.

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `MM_URL` | `http://localhost:8065` | адрес Mattermost |
| `MM_TOKEN_A` / `MM_TOKEN_B` | — | токены ботов, по порядку каталогов |
| `ALLOWED_USERS` | пусто | id пользователей, кому можно запускать споры |
| `PERSONAS_DIR` | `./personas` | где лежат каталоги персонажей |
| `PAUSE_MS` | `60000` | пауза между репликами |
| `CHECKPOINT` | `30` | автопауза каждые N реплик |
| `HARD_LIMIT` | `200` | жёсткий потолок реплик |
| `MAX_TURNS` | `6` | шагов агента на одну реплику |
| `ALLOWED_TOOLS` | `WebSearch,WebFetch` | инструменты для `claude -p` |

## Сколько это стоит

Каждая реплика — отдельный вызов `claude -p`, и в каждом едет системный контекст
Claude Code. Даже короткая реплика обходится в несколько центов. Сессии растут
по ходу спора, поэтому поздние реплики дороже ранних. В консоли виден
накопленный расход — пользуйтесь командой `стоп`.

На подписке Claude денег не спишут, но лимиты расходуются из того же пула,
что и ваша собственная работа.

## Если дать им руки

По умолчанию агенты умеют только искать в интернете. Хотите, чтобы они реально
клонировали репозитории, гоняли тесты и писали код — расширьте `ALLOWED_TOOLS`:
ALLOWED_TOOLS=Read,Write,Edit,Bash,WebSearch,WebFetch


Решайте осознанно. Они пользуются тем, что дали, а файл характера — это
пожелание, а не песочница. Если это важно — запускайте в контейнере.

## Грабли

- вебсокет через некоторые обратные прокси рвётся с кодом 1006: если бот живёт
  на одном хосте с Mattermost, укажите в `MM_URL` localhost
- получив инструменты, агенты сползают в отладку кода — говорите прямо, на каком
  уровне хотите разговор
- они уверенно выдумывают факты про вашу предметную область: просите помечать
  незнание развилкой «если так, то одно, если иначе — другое»
